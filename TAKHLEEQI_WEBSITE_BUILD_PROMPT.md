## Performance, accessibility aur responsive behavior

Adaptive particle count, capped device pixel ratio, dynamically loaded heavy 3D, compressed textures, WebP/AVIF jahan useful hon, lazy loading below the fold, fixed media dimensions aur off-screen animation pausing implement karo. Render loop mein continuous React state updates se bacho. Mobile/low-power mode halka rakho. WebGL unavailable ho to polished static/procedural fallback ho; headline aur CTAs canvas se independent hon.

Semantic landmarks, logical headings, meaningful verified alt text, keyboard navigation, visible focus, sufficient contrast, skip link aur `prefers-reduced-motion` support do. Dialogs mein focus management, Escape-to-close aur trigger par focus restoration ho. Mobile menu keyboard se accessible ho. Koi autoplaying audio na ho.

Large desktop, laptop, tablet aur mobile par inspect karo. Example widths: 1440, 1280, 768 aur 390 px; narrow 320 px par bhi overflow check karo. Typography readable ho, grids cleanly stack hon aur horizontal overflow na ho.
